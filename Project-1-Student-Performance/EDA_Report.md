# Student Performance Analysis - EDA Report

## Objective
Analyze student performance and identify factors affecting final grades.

## Dataset Information
- Records: 395
- Features: 33

## Data Cleaning
- Missing Values: 0
- Duplicate Records: 0

## Statistical Summary
- Average Final Grade (G3): 10.42
- Average Study Time: 2.04
- Average Absences: 5.71

## Outlier Detection
Outliers were analyzed using the IQR method on the final grade (G3).

## Correlation Analysis
- G2 has the strongest positive correlation with G3.
- G1 also has a strong positive correlation.
- Failures have a negative correlation with final grades.

## Visualizations
- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Correlation Heatmap

## Conclusion
Students with better first and second period grades generally achieve higher final grades. Students with previous failures tend to have lower academic performance.
