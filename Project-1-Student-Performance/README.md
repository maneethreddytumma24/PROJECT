# Student Performance Analysis

## Objective
Analyze student exam performance and identify factors affecting scores using Python.

## Dataset
Student Performance Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Tasks Performed
- Data Loading
- Exploratory Data Analysis (EDA)
- Missing Value Analysis
- Duplicate Removal Check
- Statistical Analysis
- Outlier Detection
- Correlation Analysis
- Data Visualization

## Visualizations
- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Correlation Heatmap

## Key Findings
- Dataset contains 395 students.
- No missing values.
- No duplicate records.
- G2 has the highest correlation with G3.
- Students with more failures generally score lower.
