# 💎 Project 4: Diamond Price Analysis

## 📌 Objective

The objective of this project is to analyze the Diamonds dataset to understand how different features influence diamond prices using Exploratory Data Analysis (EDA), statistical analysis, correlation analysis, and data visualization.

---

## 📂 Dataset

- **Dataset:** Diamonds Dataset
- **Source:** Kaggle
- **Records:** 53,940
- **Features:** 10

---

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

---

## 📋 Tasks Performed

- Imported and explored the dataset
- Checked missing values
- Removed duplicate records
- Calculated descriptive statistics
- Performed outlier detection using the IQR method
- Treated price outliers
- Performed correlation analysis
- Filtered and sorted data
- Used GroupBy analysis
- Created visualizations
- Generated business insights

---

## 📊 Visualizations

- 📊 Bar Graph – Diamond Cut Distribution
- 📈 Line Graph – Diamond Prices
- 📉 Histogram – Price Distribution
- 🔵 Scatter Plot – Carat vs Price
- 📦 Box Plot – Price Distribution
- 🌡️ Correlation Heatmap

---

## 🔍 Key Findings

- Carat has the strongest positive relationship with price.
- Diamonds with Ideal cuts are the most common.
- Price increases significantly with carat weight.
- Higher clarity grades generally have higher average prices.
- Outliers in the price column were detected and treated using the IQR method.
